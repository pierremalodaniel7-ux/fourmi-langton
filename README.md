# fourmi-langton

Recherche sur les fourmis de Langton généralisées (Pierre-Malo, Octave, avec Claude).

- `etat.md` : où on en est (une page)
- `journal.md` : résultats R-01 à R-35 et suivants
- `pistes.md` : prochaines pistes
- `deja_connu.md` : ce qui existe déjà dans la littérature
- `src/` : programmes C ; `outils/` : scripts
- `CLAUDE.md` : consignes pour Claude
