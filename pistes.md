# Pistes à explorer

- P1 Recherche massive d'autoroutes : règles (M, q, K), n fourmis, conditions initiales. Pour chaque autoroute : période, déplacement exact dans Z[ζ_M], règle, germe.
- P2 Classement par direction (pente) : couvrir le plus de directions possible. M = 4 ⇒ pentes rationnelles ; M = 3, 5, 8 ⇒ pentes irrationnelles possibles. (Fait en partie : R-35.)
- P3 Cycles : recherche massive ; corrélations quand les fourmis sont sur une droite y = ax.
- P4 Constructions : horloge (cycle ≈ 1,24 h à vitesse donnée), portes logiques (autoroutes + collisions), mémoire.
- P5 Au-delà de RL : q > 2, M ≠ 4.
- P6 Double Navette (R-31) : portée réglable à volonté, comme R-21 ?
- P7 Nids (R-26) : pourquoi si fréquents (74 % avec 2 restantes de classes opposées) ?
- P8 Preuve de R-14 : cases H/V (Gale-Propp-Sutherland-Troubetzkoy), quantité conservée liée à la classe.
